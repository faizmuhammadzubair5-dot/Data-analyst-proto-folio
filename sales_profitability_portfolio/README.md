# Retail Sales Profitability Analysis

## Business question
Which products and locations contribute the most profit, and how does discount level relate to profit?

## Data and tools
The project includes 2,500 deterministic simulated retail line items generated by generate_sample_data.py. Missing profit and discount values are included to demonstrate data-quality checks. No real company or customer records are used.

Tools: Python, pandas, SQLite, SQL, and Matplotlib.

## Results from the included simulated sample
- 2,500 rows were loaded; 2,468 were retained after removing 32 rows missing a required analysis field. No exact duplicate rows were found.
- Colorado had the highest total state profit in this sample: $36,563.26 across 182 line items.
- Laptop was the highest-profit product grouping: $100,623.22 across 203 line items.
- Average line-item profit was $278.71 for no discount and -$98.86 for discounts above 30%.

The sample generator intentionally makes high discounts reduce the profit margin. The discount pattern is designed into the simulation; it is not a real-world discovery.

## Run
Install packages in requirements.txt. From this folder, run generate_sample_data.py if you want to rebuild data/sales.csv, then run all cells in sales_profitability_analysis.ipynb. Tables and PNG charts are saved in outputs/.

## Limitations
The dataset is synthetic. Line-item counts are not order counts. Discount-profit patterns are descriptive and do not prove causation.
